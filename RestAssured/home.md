# 🚀 RestAssured API Automation

Bem-vindo à documentação do laboratório de **API Automation Testing** desenvolvido com Java e REST Assured.

Este repositório reúne diferentes projetos práticos voltados para **Quality Assurance, API Testing, Automation Engineering e Quality Engineering**.

## 🎯 Objetivo

O objetivo deste laboratório é demonstrar a evolução de uma solução de automação de APIs, partindo de testes funcionais básicos e evoluindo para conceitos de engenharia de automação.

Principais conceitos abordados:

* API Testing
* REST
* HTTP Methods
* HTTP Status Codes
* Request / Response
* JSON
* JSONPath
* REST Assured
* Java
* JUnit
* Maven
* DTO
* Data Driven Testing
* Parameterized Tests
* Authentication
* Token
* Dynamic Test Data
* API Validation
* CI/CD
* Performance Testing
* Quality Engineering
