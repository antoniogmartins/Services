## 🧩 Principais conceitos

### API Automation

Automação de testes funcionais sobre APIs REST.

### Data Driven Testing

Separação entre dados de teste e lógica de automação.

### DTO

Representação tipada dos objetos enviados e recebidos pela API.

### CI/CD

Execução automatizada dos testes através de pipeline.

### Performance

Avaliação do comportamento da API sob carga.
