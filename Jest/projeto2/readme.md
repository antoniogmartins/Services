## 📢 Status do Projeto

> Este repositório encontra-se em desenvolvimento ativo.

Atualmente estou construindo uma solução voltada para **Testes de Contrato (Contract Testing)**, utilizando uma arquitetura moderna baseada em:

* Jest
* Chai
* Express
* Node.js
* JSON Schema Validation

Novas funcionalidades estão sendo implementadas continuamente.

---

## 🎯 Objetivo

Garantir que consumidores e provedores de APIs mantenham contratos consistentes durante todo o ciclo de desenvolvimento, reduzindo riscos de integração e falhas em produção.

---

## 🔍 O que será abordado

### Testes de Contrato

* Validação de contratos REST
* Verificação de payloads
* Validação de schemas JSON
* Verificação de status codes
* Contratos entre Consumer e Provider

### Boas Práticas

* Service Layer Pattern
* API Object Pattern
* Reutilização de Payloads
* Separação de Responsabilidades
* Escalabilidade de Testes

### Qualidade

* Assertions robustas com Chai
* Execução automatizada com Jest
* Relatórios de execução
* Integração com CI/CD
