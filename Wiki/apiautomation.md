# 🤖 API Automation

A área de API Automation concentra os frameworks utilizados para transformar testes manuais de APIs em testes automatizados, repetíveis e integráveis ao processo de CI/CD.

---

# 🧭 Tecnologias

```text
API Automation
│
├── REST Assured
│   └── Java
│
├── Robot Framework
│   └── Python
│
└── Python
    └── API Testing
```

---

# ☕ REST Assured + Java

Principal framework utilizado para automação de APIs utilizando Java.

Tecnologias presentes nos projetos:

* Java 17
* REST Assured
* JUnit
* Maven
* JSONPath
* Jackson
* DTOs
* CSV
* Parameterized Tests
* MethodSource
* GitHub Actions

# 🚀 Objetivo

A evolução da área busca chegar a uma arquitetura de automação capaz de:

```text
Test Case
    ↓
Test Data
    ↓
API Client
    ↓
Request
    ↓
Response
    ↓
Validation
    ↓
Report
    ↓
CI/CD
```
