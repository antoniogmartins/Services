# 🐍 Robot Framework

Área dedicada à automação de testes utilizando **Robot Framework**.

---

# 🎯 Objetivo

Explorar a utilização do Robot Framework para automação de APIs e validação de cenários funcionais.

---

# 📁 Projeto

A implementação atual está localizada em:

```text
Robotframework/
└── Projeto1/
```

Entre os arquivos existentes estão:

```text
casos_testes.robot
validar_apis.robot
RobotFramework.md
robot.md
log.html
report.html
output.xml
```

---

# 🧪 Conceitos

O projeto explora:

* Test Cases
* Keywords
* API Requests
* Response Validation
* Assertions
* Relatórios
* Execução automatizada

---

# 🔄 Fluxo

```text
Robot Test
    ↓
Keyword
    ↓
API Request
    ↓
Response
    ↓
Validation
    ↓
Report
```

---

# 📊 Reports

O Robot Framework fornece artefatos de execução, incluindo:

* Log
* Report
* Output

Esses artefatos permitem analisar o resultado dos testes.
