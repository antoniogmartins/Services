# 🏗️ API Development

Esta seção será destinada ao desenvolvimento das APIs utilizadas como laboratório para os testes e automações.

---

# 🎯 Objetivo

Criar APIs controladas pelo próprio projeto permite desenvolver testes de ponta a ponta:

```text
API
 ↓
Swagger
 ↓
Postman
 ↓
Automated Tests
 ↓
Performance
 ↓
CI/CD
```

---

# 🛠️ Tecnologias planejadas

## Spring Boot

Principal tecnologia planejada para desenvolvimento de APIs utilizando Java.

## Node.js / Express

Utilizado como alternativa para desenvolvimento rápido de APIs.

## Python / FastAPI

Alternativa para desenvolvimento de APIs utilizando Python.
