# 🎯 Objetivo

Praticar testes de APIs utilizando Python, explorando operações CRUD e cenários de validação.

---

# 🧪 Escopo

O projeto trabalha com uma API pública utilizada como ambiente de testes.

Os cenários contemplam operações relacionadas a:

```text
CREATE
READ
UPDATE
DELETE
```

Também são utilizados cenários de smoke testing.
